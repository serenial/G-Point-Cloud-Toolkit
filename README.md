# G Point-Cloud Toolkit

A free and open source toolkit for LabVIEW which provides routines for working with point cloud data (by leaning heavily on (pcl)[https://pointclouds.org/])

# Licence

A licence file which contains the list of dependencies to provide to end users is under construction 

## Supported Platforms
The LabVIEW code is written in LabVIEW 2020 SP1 and provides binaries for the following platforms:

| Platform | Supported |
|----------|-----------|
| Windows x86 | 🚧 |
| Windows x64 | 🚧 |
| Linux x64 | 🚧 |
| NI-LinuxRT x64 | 🚧❔ |
| NI-LinuxRT ARM | ❌ |
| MacOS (x86-64 or Apple Silicon) | ❌ |
